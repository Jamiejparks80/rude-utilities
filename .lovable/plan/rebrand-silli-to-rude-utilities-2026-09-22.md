# Rebrand Silli to Rude Utilities

## What will change
- Replace every visible Silli name and old brand reference with **Rude Utilities** across the homepage, account, login, journey, dashboard, footer, and page-sharing details.
- Keep the existing red-and-white design, fuzzy mascot, fonts, movement, cards, and complete customer journey unchanged.
- Replace the header wordmark with a new red **Rude Utilities** logo that retains the fuzzy-eyed character detail.
- Rewrite the key customer-facing lines in a blunt, cheeky self-service voice, led by: **“Right. Let’s get on with the boring stuff.”**
- Make the self-service promise clear with lines such as **“We don’t want to talk to you. You don’t want to talk to us.”** without changing how the service works.

## Checks
- Confirm no old brand name remains visible.
- Check the homepage and main journey on desktop and mobile-sized screens.
- Confirm login, account, dashboard, and service selection still work as before.

## Technical details
- Existing internal storage keys and code type names will remain unchanged to preserve saved customer data and avoid unnecessary database changes.
- Only presentation, branding assets, visible copy, accessibility labels, and page metadata will change.
